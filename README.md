A one-star review of Monday, written as if Monday were a restaurant: the worst table, a cold to-do list for a dish, and a bill for the whole week. Short, quotable, and only true on a Monday.

## Run it

```sh
node main.ts
```

This writes the review to `/output/entry.txt`. Pass a different path as the first argument to write it elsewhere, e.g. `node main.ts /tmp/out/entry.txt`.
